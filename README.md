# NeuroLearn — بانک سؤالات نورولوژی

قالب اولیه فارسی (RTL) برای انتشار روی GitHub Pages. هر فصل فایل JSON مستقل دارد.

## انتشار
1. یک repository جدید در GitHub بسازید.
2. محتویات این پوشه را در ریشه repository بارگذاری کنید.
3. به **Settings → Pages** بروید.
4. در **Build and deployment** گزینه **Deploy from a branch** را انتخاب کنید.
5. شاخه `main` و پوشه `/(root)` را انتخاب و ذخیره کنید.
6. پس از انتشار، نشانی سایت در همین بخش نمایش داده می‌شود.

## قالب هر سؤال
```json
{
  "id": "stroke-001",
  "topic": "acute-ischemic-stroke",
  "difficulty": "متوسط",
  "stem": "صورت سؤال",
  "options": ["گزینه الف", "گزینه ب", "گزینه ج", "گزینه د"],
  "correctIndex": 0,
  "explanation": "توضیح پاسخ صحیح",
  "wrongOptionExplanations": ["توضیح گزینه الف", "توضیح گزینه ب", "توضیح گزینه ج", "توضیح گزینه د"],
  "examTrap": "نکته آزمونی"
}
```
`correctIndex` از صفر شروع می‌شود. این بسته فعلاً قالب پایه است و هنوز بانک سؤال کامل یا ثبت پاسخ ندارد. محتوای پزشکی باید پیش از استفاده آموزشی با منابع معتبر و راهنماهای به‌روز تطبیق داده شود.
